/*
    Sandbox options for ImmersiveBombs.

    These are gameplay settings - they mutate the world and resolve server-side -
    so they live here rather than in PZAPI.ModOptions, which is client-local and
    would desync in multiplayer. They appear as their own "Immersive Bombs" page
    in the Sandbox Options screen, in the server settings editor, and in the
    in-game admin/debug sandbox editor.

    Parsing traps (CustomSandboxOptions.readFile / ScriptParser):
      - readFile concatenates lines with NO separator, so every entry must be
        terminated by its own comma, including the last one before a closing brace.
      - stripComments only understands block comments. A // comment would swallow
        the rest of the file, because the newline that should end it is gone.

    Reached from Lua as SandboxVars.ImmersiveBombs.<name>, or - always current,
    even after a mid-game admin edit - getSandboxOptions():getOptionByName().
*/

VERSION = 1,

option ImmersiveBombs.Enabled
{
    type = boolean,
    default = true,

    translation = ImmersiveBombs_Enabled,
